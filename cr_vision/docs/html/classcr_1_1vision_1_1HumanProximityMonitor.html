Detailed Description

Monitors how close humans are to the robot.

The node subscribes to a PoseArray topic that provides positions of humans. It uses TF2 to get the transform from the world frame to the end-effector ("tool0") and calculates the horizontal (XY) distance between each human and the robot tool. If any distance is below the configured safe_distance, it publishes true, otherwise false.

void cr::vision::HumanProximityMonitor::human_poses_callback ( const geometry_msgs::msg::PoseArray::SharedPtr  msg)
private

Callback for incoming human PoseArray messages.

Transforms each human pose into the "tool0" frame, then computes the XY-plane distance between the robot tool and each human. If any human is closer than safe_distance_, it sets human_near to true. Finally, it publishes the result on "/cr/human_near".

Parameters
msgShared pointer to the PoseArray message with human poses.
