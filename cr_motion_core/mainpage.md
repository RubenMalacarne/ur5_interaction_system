# cr_motion_core
`cr_motion_core` provides an asynchronous interface for controlling a robot arm and gripper using MoveIt.

It abstracts the MoveGroupInterface into a clean, non-blocking command layer, ideal for integration into behavior trees.

The module handles motion planning, execution, and status tracking for both arm and gripper.
