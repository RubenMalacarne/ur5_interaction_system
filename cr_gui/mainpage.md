# cr_gui

The `cr_gui` package integrates Qt with ROS 2, providing a graphical interface to monitor the robotic workflow in real time.  
It is designed to visualize camera feeds with object detections, show workflow status and progress, and display structured log messages to assist the operator.

## Components
- `ImageWidget`: widget for displaying RGB camera frames with detected objects.
- `GuiNode`: main window that renders the camera feed and workflow status for operator supervision.
